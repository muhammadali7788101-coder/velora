# VELORA — шаблон сайта ресторана

## Быстрый запуск
1. Распакуйте архив.
2. Откройте папку проекта в VS Code.
3. Запустите `index.html` через Live Server (рекомендуется) или разместите папку на статическом хостинге.
4. Откройте `js/config.js` и укажите адрес собственного проекта Mokky.dev, нужные имена ресурсов, контакты и ссылки социальных сетей.

## Ресурсы Mokky.dev
Создайте ресурсы с именами, указанными в `js/config.js` (по умолчанию `menu`, `orders`, `reserve`, `messages`).

Рекомендуемые поля:
- `menu`: `title` (string), `desc` (string), `price` (number), `category` (string), `image` (string), `available` (boolean).
- `orders`: `clientName`, `phone`, `address`, `deliveryType`, `comment`, `items` (array), `totalPrice` (number), `date`, `status`.
- `reserve`: `clientName`, `phone`, `date`, `time`, `guestsCount`, `tableType`, `comment`, `status`, `createdAt`.
- `messages`: `customerName`, `customerPhone`, `email`, `message`, `read`, `createdAt`, `source`.

Для публичной демонстрации формы отправляют записи в соответствующие ресурсы. Проверьте права доступа и не храните секретные ключи в клиентском JavaScript. Публичный клиентский шаблон не может безопасно хранить приватный API-токен.

Сообщения из формы контактов отображаются в разделе «Сообщения» административной панели.

## Корзина
Корзина хранится в `localStorage` конкретного браузера. Она не требует отдельного ресурса Mokky и не смешивается между посетителями. При оформлении заказа снимок корзины отправляется в `orders`; локальная корзина очищается только после успешного ответа сервера.

## Админ-панель
Откройте `admin/index.html`. Вход в этой версии — демонстрационный клиентский пароль из `js/config.js`. Начальный демонстрационный пароль: `velora2026`. Он не является серверной авторизацией и не защищает публичные ресурсы Mokky.dev. Используйте только для демонстрации/локального шаблона; для реальных заказов настройте серверную авторизацию и ограничения доступа.

## Ссылки социальных сетей
В `js/config.js` заполните `socialLinks.instagram`, `socialLinks.telegram` и `socialLinks.whatsapp` полными HTTPS-ссылками. Пока поле пустое, соответствующая иконка отображается как неактивная заглушка.

## Важно перед публикацией
- Замените название, контакты, адреса, тексты и изображения.
- Замените демонстрационный пароль.
- Настройте ресурсы Mokky.dev и проверьте права доступа.
- Подготовьте собственную политику конфиденциальности.
- Укажите реальные ссылки социальных сетей и карту.
- Проверьте сайт на мобильных устройствах.
