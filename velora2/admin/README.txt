АДМИН-ПАНЕЛЬ VELORA

Откройте admin/index.html через локальный сервер (например, VS Code Live Server).
Общие настройки API, названия ресурсов и демонстрационный пароль находятся в ../js/config.js. Демонстрационный пароль по умолчанию: velora2026.

ВНИМАНИЕ: вход в этой версии является демонстрационной проверкой на стороне браузера. Он не защищает API и не подходит для реального хранения чувствительных данных. Не размещайте приватные ключи в клиентских файлах.

Для работы создайте ресурсы menu, orders и reserve в Mokky.dev. Подробности — в корневом README.md.
