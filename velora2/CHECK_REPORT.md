## Проверено статически

- Синтаксис всех JavaScript-файлов через `node --check`.
- Локальные пути HTML `src`/`href` и CSS `url(...)`/`@import`.
- Наличие локальных JavaScript и CSS файлов, подключённых страницами.
- Структура основных форм: заказ, бронирование, контактное сообщение и вход в админ-панель.

## Найденные ограничения и риски

1. **Админ-панель не защищает API.** Пароль хранится в клиентском `js/config.js`, а проверка выполняется в браузере. Посетитель может открыть исходный код и увидеть пароль или обращаться к Mokky.dev напрямую. Для реального запуска нужна серверная авторизация и серверные правила доступа к данным.
2. **Mokky.dev не проверен вживую.** В архиве нет доступа к панели проекта, поэтому нельзя подтвердить существование ресурсов `menu`, `orders`, `reserve`, `messages`, их поля и права доступа.
3. **Визуальный браузерный тест не выполнен.** Статическая проверка не заменяет тестирование в реальном браузере на компьютере и телефоне.
4. **Демонстрационные данные требуют замены.** Контакты, адрес, соцсети, изображения и юридический текст нужно проверить и заменить на реальные перед публикацией.

## Ресурсы Mokky.dev

В `js/config.js` указаны ресурсы `menu`, `orders`, `reserve`, `messages` и API URL. Убедитесь, что они созданы в вашем проекте и что публичные права не позволяют посторонним читать, изменять или удалять приватные записи.
